STEP 2 — Patch dex-query.py
---------------------------------------------------------------------

ADD at the top of dex-query.py (after existing imports):

  from dex_weights import weighted_query, print_weight_stats

FIND the section that runs the ChromaDB query
(likely something like):

  results = collection.query(
      query_embeddings=[embedding],
      n_results=n_results,
      include=["documents", "metadatas", "distances"]
  )

      query_text=query,
      n_results=n_results,
      include_external=args.external if hasattr(args, 'external') else False
  )

ADD --external flag to dex-query.py argument parser:

  parser.add_argument("--external", action="store_true",
      help="Include ext_canon and ext_archive in search")

ADD --weight-stats flag:

  parser.add_argument("--weight-stats", action="store_true",
      help="Show source weight table and exit")

ADD handler early in main():

  if args.weight_stats:
      print_weight_stats()
      sys.exit(0)

UPDATE result display to show provenance:

  for r in results:
      print(f"[{r['label']}] {r['weighted_score']:.4f} — {r['filename']}")
      print(r['document'][:500])

STEP 3 — Patch dex-bridge.py
---------------------------------------------------------------------

ADD at the top of dex-bridge.py (after existing imports):

  from dex_weights import weighted_query_with_provenance

FIND the RAG retrieval call (likely):

  results = collection.query(...)

REPLACE with:

      query_text=user_query,
      n_results=5,
      include_external=args.external if hasattr(args, 'external') else False

FIND where RAG context is assembled for the prompt:

  context = "\n\n".join([r['document'] for r in results...])

UPDATE to include provenance in the injected context:

  context_chunks = [r['document'] for r in rag_results]
  context = "\n\n".join(context_chunks)
  context_with_provenance = f"{provenance}\n\n{context}"

  # Then pass context_with_provenance into the generation prompt

ADD --external flag to dex-bridge.py argument parser:

  parser.add_argument("--external", action="store_true",
      help="Include external corpus in RAG retrieval")

=====================================================================
WEIGHT TUNING (if results still feel wrong after patching)
=====================================================================

Edit these values in dex-weights.py:

  FILE_TYPE_WEIGHTS = {
      "council_review": 1.10,  # raise if reviews still losing
      "text_message":   0.90,  # lower if texts still winning
      "thread_export":  0.88,  # lower if ChatGPT threads dominate
      ...
  }

The weights are relative — what matters is the ratio between tiers,
not the absolute values. Governed docs should be 15-25% heavier
than casual archive material.
